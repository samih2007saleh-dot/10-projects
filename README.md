# 10-projects
10 small projects in java to learn and be similar to coding.

# the Projects:

10 Beginner Java Projects (in increasing difficulty)
1️⃣ Simple Calculator

What you’ll learn: variables, operators, Scanner, if / switch

Add, subtract, multiply, divide

Bonus: handle division by zero

2️⃣ Number Guessing Game

What you’ll learn: loops, Random, conditions

Program picks a random number

User keeps guessing until correct

Show number of attempts

3️⃣ Student Grade Calculator

What you’ll learn: methods, averages, conditionals

Input multiple grades

Calculate average

Print letter grade (A, B, C…)

4️⃣ Simple Login System (Console)

What you’ll learn: strings, comparisons, logic

Hard-coded username & password

Allow 3 attempts only

Print success or lock message

5️⃣ To-Do List (Console)

What you’ll learn: arrays or ArrayList

Add tasks

View tasks

Remove tasks

Exit menu

6️⃣ Bank Account Simulation

What you’ll learn: classes & objects

Create Account class

Deposit / Withdraw

Show balance

Validate insufficient funds

7️⃣ ATM Menu System

What you’ll learn: combining everything

PIN validation

Balance inquiry

Withdraw / Deposit

Loop menu until exit

8️⃣ Word Counter

What you’ll learn: strings & loops

Count characters

Count words

Count vowels

Ignore spaces

9️⃣ Simple Quiz Application

What you’ll learn: methods, arrays, control flow

Multiple-choice questions

Keep score

Show result at the end

🔟 Mini Address Book

What you’ll learn: objects + lists

Store name, phone number

Add / search / delete contacts

Print all contacts

If you want ONE rule:

If a project feels hard — that’s perfect. That’s where learning happens.

Java Topics You Should Review (in this order)

Variables & Data Types

if / else & switch

Loops (for, while)

Methods

Arrays & ArrayList

Classes & Objects

Basic String methods

Input with Scanner
